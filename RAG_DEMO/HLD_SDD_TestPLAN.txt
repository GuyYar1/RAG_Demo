1. **Input Query**: User inputs a question related to diabetic retinopathy.
2. **Embedding Generation**: The query is converted into an embedding.
3. **Document Retrieval**: Relevant documents or chunks are retrieved from the in-memory vector store.
4. **Response Generation**: The retrieved information is passed to the LLM (BioMistral or TinyLlama) to generate a human-like response.
5. **Output Response**: The generated response is sent back to the user.

#### **2.3. Detailed System Flow**

1. **User Query**:

   * The user inputs a query through the front-end interface.
2. **Embedding**:

   * The query is sent to the **Nomic-Embed-Text** model, which generates an embedding.
3. **Retrieval**:

   * The embedding is compared with stored document embeddings in the **vector store**.
   * The most relevant document chunks are retrieved.
4. **LLM Response**:

   * The retrieved document chunks are passed to the **BioMistral** or **TinyLlama** model for response generation.
5. **Return Output**:

   * The final response is sent to the front-end UI.
